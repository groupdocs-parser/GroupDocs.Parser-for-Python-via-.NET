# GroupDocs.Parser for Python via .NET - AGENTS.md

> Instructions for AI agents working with **Python via .NET** examples in this repository.

GroupDocs.Parser for Python via .NET extracts text, images, attachments, barcodes, and structured content from **65+** document and related formats via a .NET-powered API used from Python.

**Supported formats:** **65+** - [https://docs.groupdocs.com/parser/python-net/supported-document-formats/](https://docs.groupdocs.com/parser/python-net/supported-document-formats/)

**Human overview:** see [README.md](README.md).

## Install

```bash
pip install groupdocs-parser-net
```
